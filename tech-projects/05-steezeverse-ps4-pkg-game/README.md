# STEEZEVERSE — Original PS4 Homebrew Game

## Objective
Design and code an original turn-based tactics/RPG game featuring an original superhero roster (Central Alliance), built with the OpenOrbis toolchain and packaged as a working PS4 homebrew PKG.

## What I did
- Wrote the full game design doc: 3-act story arc, 8 playable heroes, individual movesets and team-up mechanics
- Built the C++ tactics engine
- Packaged and ran the final build as a PKG on a jailbroken PS4

## Relevant skills
- C++ development and game engine architecture
- Working within a homebrew/unofficial SDK (OpenOrbis) and console packaging format
- End-to-end project ownership: design doc through shipped, running build
